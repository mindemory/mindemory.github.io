Thanos

A lab's memory: what the lab has worked out over the years, kept in one place to search, and still there after the people who knew have moved on.

Every lab relearns the same things: which grant pays for scans, what the chart string is, who holds the lab card, which toolboxes to install, where the code lives. Most of it lives with the advisor, or with the postdoc who left. Thanos keeps it where the whole lab can search it, so nobody has to ask the same question every year.

What it does

  • Search before you ask: every question, every answer and the lab's GitHub repositories, searched as you type. Forms of a word meet (scans, scanning, scanned), and so do the words labs use for the same thing (MRI, scan, fMRI).
  • Ask once: while you type a question, it shows the answers that may already be there. If none fits, the question goes on the lab's Open list for whoever knows.
  • Anyone can answer or improve anything: every version is kept, with who wrote it, so an edit never loses anything.
  • Still right? Anyone can mark an answer as still right. One that nobody has checked in a year is marked as possibly out of date.
  • Alumni keep their place: people join by an invite link, and those who move on become alumni. They can still read and answer, and what anyone wrote stays under their name.
  • Secrets stay out: saving something that looks like a card number, a password or a key asks first, because everyone in the lab can read it, including people who join years from now.
  • Keep a copy: any member can download the whole lab as Markdown, or as JSON with every version.

A new lab starts with the questions nearly every lab gets asked, left open for the people who know. Thanos makes nothing up about a lab.

Where it stands

It's early. It started for the Murray Lab at Dartmouth, where I'm a postdoc, and the Clay Space Lab at NYU, where I did my PhD, and it's meant for any lab or group that keeps relearning the same things. It hasn't yet been tried by other labs.

Try Thanos

On your computer

With Node.js 20.9 or later installed:

git clone https://github.com/mindemory/thanos && cd thanos && npm install && npm run dev

Then open http://127.0.0.1:4848. A local copy needs nothing else: its database stays in the folder, and the sign-in link shows on the page instead of in an email.

Thanos on GitHub

For your lab

A lab's own copy needs a Postgres database (a free Neon project works), Resend for sign-in emails, and a host such as Vercel. Put the accounts in the lab's name, not one person's: Thanos is for when people leave, and that includes whoever set it up.
